GITHUB PAGES
1. Create/open a GitHub repository.
2. Upload index.html and the assets folder.
3. GitHub: Settings -> Pages -> Deploy from branch -> main -> / (root).
4. Open the resulting GitHub Pages address on the iPad.
5. In Safari, use Share -> Add to Home Screen -> Open as Web App.
